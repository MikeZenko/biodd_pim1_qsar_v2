# Archive

This directory preserves material that is intentionally outside the canonical
v2 evidentiary boundary.

- `legacy_v1/` contains the complete earlier QSAR workflow and its outputs.
- `workspaces/` contains non-canonical rendering and visual-inspection scratch.
- `local_state/` contains caches and machine-local session files retained during
  cleanup rather than deleted.

Only `legacy_v1/` is a reproducible historical project. The other directories
are retained for traceability and may contain machine-specific paths.
